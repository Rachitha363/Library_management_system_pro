📚 Online Library Management System
An interactive web portal designed to automate various manual processes involved in managing a library — from book issuance to member management.

🔍 Project Overview
This system provides an efficient way to handle tasks traditionally performed by librarians, such as issuing books, managing student and book records, tracking returns and fines, and more. By reducing paperwork and increasing transparency, it aims to improve the overall library experience for both students and administrators.

✨ Features
- 🔐 Admin Login
- 📖 Book Search (by title, author, or ISBN)
- ✅ Book Issue and Return Tracking
- 💸 Fine Calculation and Monitoring
- 🧑‍🎓 Member (Student) Management
- 📚 Book Inventory Management
- 🔄 Status Update for Book Availability
- 📊 Admin Dashboard with full control

🧩 Modules
- Admin Dashboard
- Manage Books: Add, update, delete book records
- Manage Members: Add, update, delete student/member records
- Book Transactions: Issue and return books
- Fine Management: Track overdue and fines

🛠️ Technology Stack

| Layer        | Technology            |
|--------------|------------------------|
| Frontend     | HTML, CSS, JavaScript |
| Backend      | PHP                   |
| Database     | MySQL                 |
| Server       | XAMPP / WAMP / MAMP   |

⚙️ Installation Guide

1. 🔽 Clone or download this repository.
2. 🗃️ Copy the project folder to your web server directory (`htdocs` for XAMPP or `www` for WAMP).
3. 🗄️ Import the SQL file from the `db/` folder into **phpMyAdmin**.
4. ⚙️ Open `dbcon.php` and configure your DB credentials.
5. 🌐 Open your browser and go to:  
   `http://localhost/Library_management_system_pro/`
   
🧪 Requirements
- PHP >= 7.x
- MySQL
- Web server (Apache via XAMPP/WAMP/MAMP)
